Privacy Policy

Application: Valheim rclone Backup

Last updated: October 19, 2026

Purpose and data access

This is a personal, non-commercial application used only by its owner. It uses rclone and Google Drive authorization to read, upload, organize, and restore the owner's Valheim game server backup files.

Data use and sharing

Authorized Google Drive data is used only to carry out backup and restoration operations requested or configured by the owner. The application does not sell Google user data or share it with advertisers.

Storage and security

Backup files are stored in the owner's Google Drive account. OAuth credentials are stored privately in the owner's server configuration and are not published on this website.

Data retention and deletion

The owner controls the stored backups and can delete them from Google Drive. Access can be revoked through the owner's Google account security settings.

Contact

For privacy questions, use the support contact specified on the Google OAuth consent screen for this application.
